# 10 输入输出、文件处理与异常

## 异常处理

### 原笔记写法

```cpp
catch (invalid_argument &e)
{
    cout << "\n\nException: " << e.what() << endl;
}
```

### 整理结论

- `catch` 用来捕获 `try` 中抛出的异常
- `invalid_argument` 在 `<stdexcept>` 中
- 用引用接收异常对象可以避免不必要拷贝

## 输入运算符 `operator>>`

原始笔记在 `10.2` 里反复解释了流提取运算符。
真正要记住的是：

- 它通常返回 `istream&`
- 这样才能支持链式输入
- 可以结合 `setw`、`ignore` 做安全读取

## 文件与流的思维方式

- 输入流：从外界读进程序
- 输出流：从程序写到外界
- 重载 `<<` / `>>` 时，要尽量保持和标准流一致的使用习惯

## 安全接口设计

原始笔记里 `badSetHour` 的案例很典型：

- 返回私有成员的非常量引用，会破坏封装
- 安全做法是 `void setHour(...)` 或返回值拷贝

这类案例本质上说明：
“能写出接口”不代表“接口设计安全”。
