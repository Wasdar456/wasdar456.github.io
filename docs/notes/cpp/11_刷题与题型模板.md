## 多数元素：摩尔投票

### 结论

- 用一个候选人和一个计数器
- 相同加一，不同减一
- 若题目不保证多数元素存在，最后还要验证一次

## 字符串左旋

### 模板

三次反转：

1. 反转前半段
2. 反转后半段
3. 反转整体

## 反转链表

### 模板

```cpp
ListNode* prev = nullptr;
ListNode* curr = head;
while (curr != nullptr) {
    ListNode* next = curr->next;
    curr->next = prev;
    prev = curr;
    curr = next;
}
```

## 棒球计分题：接口修正思路

原始草稿里这一题最大的价值不只是答案，而是“如何定位错法”：

- 头文件缺失

- 不合法的负索引
- `stoi` 漏用
- `if` 链断裂

## 浮点到整数的稳定写法

原始 ACM 笔记里的金句保留如下：

> 能用整数除法代替小数乘法，就尽量不要用小数。

典型替换：

- `floor(x * 0.1)` -> `x / 10`
- `floor(x * 1.5)` -> `(x * 3) / 2`
