# 06 数组、字符串与格式化输出

## `std::string`

重点整理自 `10.1` 一段和旧笔记碎片：

- `.size()` 与 `.length()` 等价
- `getline(cin, s)` 读整行
- `substr(pos, len)` 取子串
- 与 C 风格字符串相比，`std::string` 更安全

## `getline` 易错点

在 `cin >> x` 之后直接 `getline`，容易读到残留换行。
必要时先 `cin.ignore(...)`。

## 格式化输出：`setw` 与 `setfill`

原始刷题笔记里特别提到这一行：

```cpp
os << setfill('0') << setw(2) << h << ":"
   << setw(2) << m << ":" << setw(2) << s;
```

### 要点

- `setw(2)` 只影响“下一个输出字段”
- `setfill('0')` 会持续生效，直到被新的填充字符覆盖
- 这组写法常用于时间、日期、编号补零

### 示例

```cpp
cout << setfill('0') << setw(2) << 7;   // 输出 07
```

## 数组与容器

- 内建数组不能直接整体赋值
- `std::array` 可以拷贝和赋值
- `range-based for` 中，值遍历和引用遍历要区分

```cpp
for (auto x : arr) { }   // 拷贝
for (auto& x : arr) { }  // 引用
```
