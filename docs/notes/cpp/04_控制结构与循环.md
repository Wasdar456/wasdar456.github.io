## `if / else` 配对规则

`else` 总是匹配最近且尚未匹配的 `if`。
这也是为什么课堂和考试里建议一律写花括号。

## `switch`

- `case` 后面接常量表达式
- 没有 `break` 会贯穿

## `do-while`

### 原笔记写法

```cpp
Do{ Int i = 3; ... }while(i<=6)
```

### 修正版

```cpp
int i = 3;
do {
    // ...
} while (i <= 6);
```

### 原因

- 关键字大小写错误
- 原写法里的 `i` 作用域不够，`while` 条件处不可见

## 死循环高频陷阱

- `unsigned i >= 0` 永远为真
- 浮点数做精确相等比较不安全
- `for(;;)` 是合法死循环

## 来自刷题笔记的补充

反转链表时，循环里一定先存 `next` 再断链：

```cpp
ListNode* next = curr->next;
curr->next = prev;
```

这类“先保存再修改”的顺序问题，本质上也是控制流程里的稳定性问题。
