# 09 继承、多态与虚函数

## 继承

继承让派生类复用基类的接口和部分实现，但不要把“能继承”理解成“能随便访问私有成员”。

## 多态

本章沿用原始笔记里的主线：

- 多态的前提是基类接口被声明为 `virtual`
- 真正的动态绑定发生在“基类指针 / 基类引用 指向派生类对象”时

## 为什么对象本身不行

如果直接把派生类对象赋给基类对象，会发生对象切片，动态类型信息被截断。
所以教学示例里总强调“用指针或引用看多态”。

## 虚函数表

考试记忆层面只要掌握：

- 编译器通常会为含虚函数的类建立虚函数表
- 运行时通过对象中的隐藏信息找到对应函数入口

不需要把实现细节神化成编译器魔法，只要知道它支持动态绑定即可。

## 虚析构函数

如果基类会被拿来做多态删除，应把析构函数写成 `virtual`。

```cpp
virtual ~Base() = default;
```

否则通过基类指针删除派生类对象时，可能析构不完整。
