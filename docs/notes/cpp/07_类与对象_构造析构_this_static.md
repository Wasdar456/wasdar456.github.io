# 07 类与对象、构造析构、`this`、`static`

## 句柄的三种形式

原笔记里这几句值得保留：

- 对象名可以当作访问成员的句柄
- 指针可以当作访问对象的句柄
- 引用是对象的别名，也可直接访问成员

## 构造函数

- 默认构造函数
- 拷贝构造函数
- 移动构造函数
- 构造函数委托
- 成员初始化列表

## 析构函数

整理后的核心结论：

- 名字是 `~类名`
- 没有参数、没有返回值、不能重载
- 作用是做资源清理，不是负责释放对象自身内存
- RAII 依赖析构函数来回收资源

## 构造与析构顺序

### 构造顺序

1. 基类
2. 成员对象，按声明顺序
3. 派生类构造函数体

### 析构顺序

与构造相反。

## `static` 数据成员

- 属于整个类，不属于某个对象
- 类内声明，类外定义

## `static` 成员函数

- 没有 `this`
- 不能直接访问普通成员
- 适合处理类级别的信息
