# 05 函数与重载、默认参数

## 函数声明与定义

- 原型用于告诉编译器函数签名
- 返回值类型不是重载依据
- 默认参数必须从右往左连续给出

## `const` 成员函数

原始笔记里这一块非常重要，整理成一句话：

> `const` 对象只能调用 `const` 成员函数。

## 为什么 `get` 也要加 `const`

编译器不会“猜这个函数看起来只读”，它只认函数签名上有没有 `const`。

### 正确写法

```cpp
unsigned int getMonth() const { return month; }
```

## 友元函数

友元函数不是成员函数，但可以访问类的私有成员。常见用途：

- `operator<<`
- `operator>>`
- 某些需要对称参数的运算符重载

## 友元类

友元类表示“整个类都被授权访问另一个类的私有成员”。
记住三个限制：

- 不传递
- 不继承
- 单向

## 默认参数与重载的风险

默认参数和函数重载混用时，容易造成调用二义性。
考试里如果让你设计接口，优先保证“调用看一眼就知道落到哪个版本”。
