# 03 作用域、引用与指针

## `&` 的三种含义

- 类型后：引用声明符
- 变量前：取地址
- 表达式中间：按位与

这个点来自原始笔记里对 `const string &first` 的反复解释，必须背熟。

## 引用 vs 指针

### 引用

- 是别名
- 声明时必须初始化
- 不能改绑
- 常用于参数传递和返回别名

### 指针

- 存地址
- 可以为空
- 可以改指向
- 访问目标时要解引用或用 `->`

## 原笔记中的指针示例

### 原笔记写法

```cpp
class Myclass{
    public:
    int sum;
    void func(){}
};
Myclass obj;
MyClass *ptr = &obj
ptr ->num = 20;
ptr ->func();
```

### 修正版

```cpp
class MyClass {
public:
    int sum;
    void func() {}
};

MyClass obj;
MyClass* ptr = &obj;
ptr->sum = 20;
ptr->func();
```

### 原因

- 类名大小写不一致
- 漏分号
- 成员名写成了不存在的 `num`

## `const string&` 为什么常用

- 避免大对象值传递拷贝
- 保证函数内部不改实参
- 可以绑定临时对象

这是构造函数参数、运算符重载和只读访问器里最常见的形态之一。
