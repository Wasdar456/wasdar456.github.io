我是 `Wasdar456`，华南理工大学人工智能专业本科生。这个站点服务于长期复习：每一页都应当能够回答“定义是什么、为什么成立、什么时候失效、如何验证”。

## 公开边界

- 公开：经过重写和来源核验的课程知识、公开论文精读、已公开基线的白名单复现。
- 不公开：真实姓名、学号、私人联系方式、教师与合作者私人信息。
- 不公开：新方法、论文 idea、未投稿稿件、内部评审、实验结果、关键超参数、失败轨迹、运行日志与服务器信息。
- 不公开：没有明确再分发许可的课件、教材、试卷和答案。

发现公开知识错误时，可以通过本站 GitHub 仓库提交 issue；请不要在 issue 中粘贴私人课程材料或敏感信息。
