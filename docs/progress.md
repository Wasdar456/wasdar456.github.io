# 学习进度

进度表示公开笔记的覆盖程度，不表示考试成绩，也不包含私有研究工作。权威状态来自自动生成的[全站课程目录](generated/course-catalog.md)。

## 掌握状态

| 状态 | 含义 | 下一步 |
|---|---|---|
| 已发布 | 达到结构与篇幅门槛，来源可追溯 | 定期复查数值、链接和边界 |
| 复习中 | 已发布，但仍在做例题与校对 | 补充反例和自测结果 |
| 待整理 | 有课程材料或学习计划 | 不生成占位文章 |
| 私有 | 涉及研究边界或无授权材料 | 不同步、不链接、不公开 |
