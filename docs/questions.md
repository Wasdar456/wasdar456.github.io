# 未解决问题

这里保存公开知识层面的疑问，不放新方法、未投稿故事线、内部实验和关键超参数。

| 方向 | 问题 | 当前判断 | 验证方式 |
|---|---|---|---|
| 优化 | Adam 的自适应缩放何时会降低泛化？ | 与任务、正则化和学习率调度共同相关 | 固定预算比较 SGD、AdamW，多随机种子报告区间 |
| 归一化 | 小批量与长序列下不同归一化的误差传播如何变化？ | 不能只比较单次验证集精度 | 对齐参数量、吞吐和优化器后做消融 |
| Flow Matching | 更直的条件路径是否必然带来更少的数值求解步数？ | 不必然；还受学习到的边际场与求解器影响 | 同一网络、容差和求解器比较 NFE—误差曲线 |
| VLA | 动作分块长度怎样影响反应速度与动作连贯性？ | 更长分块提升连贯性但可能放大开环偏差 | 固定频率比较不同 chunk 与重规划策略 |
