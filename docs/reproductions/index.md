# 复现记录

首版只建立审核框架，暂不发布研究实验。一个复现页面上线前必须同时满足：方法已经公开、数据与代码许可证允许、运行环境可公开、结果不来自私有研究主线、所有输出通过逐项白名单。

## 记录结构

1. 目标声明与“不复现什么”。
2. 论文版本、代码提交、数据版本和许可证。
3. 环境锁定、硬件预算和随机种子。
4. 最小运行命令与期望输出。
5. 结果表、误差区间和与论文差异。
6. 失败排查，但移除凭据、服务器地址和私有路径。
7. 可复现性结论与停止条件。

新的公开记录请从[复现模板](../writing-guides/reproduction.md)开始。
